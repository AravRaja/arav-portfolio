# rocketbox-female-12/model.glb

Source: Microsoft Rocketbox Avatar Library, avatar `Assets/Avatars/Adults/Female_Adult_12` (mesh `f012_hipoly_81_bones`)
https://github.com/microsoft/Microsoft-Rocketbox/tree/master/Assets/Avatars/Adults/Female_Adult_12

Licence: MIT. The library was first released (March 2020) for research and academic use only; the repository
README records "12/2020: Updated license to MIT" and "November 2020 License Update: The library of avatars is
now released under MIT License", and the repository's LICENSE.md (reproduced below) is the MIT licence.

Changes made here: converted FBX -> GLB in Blender 3.0 (skinned mesh + 80-bone Biped skeleton, no animation,
no facial blendshapes), base-colour textures only (body 2048 -> 1024 px JPEG, head 2048 -> 512 px JPEG,
opacity map -> 512 px PNG where the avatar has one), normal and specular maps dropped.
